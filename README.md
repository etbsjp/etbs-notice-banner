# ETBS Notice Banner

トップページのヘッダー直下（スライダーの上）に、休業日などのお知らせを表示する WordPress プラグインです。

## できること

- 管理画面の「お知らせバナー」で、**見出し・本文・掲載開始日・掲載終了日**を入力するだけでお知らせを出せます
- 編集者（投稿の編集ができる人）も書き換えられます。見た目（色・太さ・配置）はプラグイン側で固定しているので、崩れません
- 掲載開始日はその日の0時から、掲載終了日はその日の23時59分まで表示し、翌日から自動で表示しなくなります
- ページ全体がキャッシュされるサイトでも、掲載終了を過ぎたお知らせはブラウザ側でも取り除きます
- 出し方は PC・スマホそれぞれ「下の画像に重ねる」「帯として置く」から選べます（管理者だけが変更できます）

## 使い方

1. 「お知らせバナー」を開く
2. 見出し（例：休業日のお知らせ）と本文（例：2026年10月7日(水)・10月13日(火)）を入力する
3. 必要なら掲載開始日・掲載終了日を入れて「保存」

表示をやめるときは、本文を空にして保存します。

## 注意事項

- 表示はトップページだけです
- 既定では、Lightning（G2 系）のヘッダー直後の差し込み口 `lightning_header_after` に出します。テーマが違う場合は、下のフィルターで差し込み口を変えてください
- My WP など、役割ごとに管理メニューを描き直すプラグインを使っているサイトでは、編集者のメニューに「お知らせバナー」を追加する設定が別途必要です

## フィルター

| フィルター | 既定値 | 用途 |
|---|---|---|
| `etnb_output_hook` | `lightning_header_after` | お知らせを出す差し込み口（アクション名） |
| `etnb_overlay_top` | `8px` | 重ねるときの、下の要素の上端からの余白（数値＋単位のみ） |
| `etnb_should_display` | トップページかつ掲載期間内なら `true` | 表示するかの最終判断 |
| `etnb_cache_note` | 反映まで数分かかる旨の文 | 管理画面の下に出す注意書き |
